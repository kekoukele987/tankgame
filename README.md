# 坦克大战游戏

基于 Pygame 开发的经典坦克大战游戏。

## 项目结构

```
tank/
├── main.py                # 程序入口 - 初始化窗口并启动游戏
├── config.py              # 配置文件 - 常量、颜色、游戏参数
├── sprites.py             # 精灵模块 - 坦克、子弹、墙壁、爆炸等游戏对象
├── game_manager.py        # 游戏管理 - 初始化、更新、碰撞检测、关卡管理、UI
├── level_transition.py    # 关卡过渡动画 - 过场特效、粒子系统
├── README.md
└── .gitignore
```

## 快速开始

```bash
# 安装依赖
pip install pygame

# 启动游戏
python main.py
```

## 操作说明

| 按键 | 功能 |
|------|------|
| WASD / 方向键 | 移动坦克 |
| 空格 | 射击 |
| P | 暂停/继续 |
| R | 重新开始（游戏结束/通关后） |
| ESC | 退出游戏 |

## 游戏特性

- 共 5 关，每关敌人数量递增
- 砖墙可被摧毁（3次），钢铁墙不可摧毁
- 玩家 3 条命，被击中后短暂无敌（闪烁效果）
- 敌方 AI 会追击玩家
- 关卡过渡动画（粒子特效、星星背景、文字动画）
- 暂停、游戏结束、胜利界面

## 模块说明

- **config.py**: 集中管理所有游戏常量，便于调整游戏参数
- **sprites.py**: 所有游戏对象的类定义，每个类职责单一
- **game_manager.py**: 核心游戏逻辑，包括初始化、更新循环、碰撞处理、关卡切换、UI渲染
- **level_transition.py**: 独立的关卡过渡动画模块，可复用
- **main.py**: 最简入口，只负责初始化 pygame 和启动 GameManager

## 技术栈

- Python 3
- Pygame 2.x

# 坦克大战游戏

基于 Pygame 开发的经典坦克大战游戏，支持随机地图和**自定义地图编辑器**。

## 项目结构

```
tank/
├── main.py                # 程序入口 - 初始化窗口并启动游戏
├── config.py              # 配置文件 - 常量、颜色、游戏参数
├── sprites.py             # 精灵模块 - 坦克、子弹、墙壁、爆炸、道具
├── game_manager.py        # 游戏管理 - 初始化、更新、碰撞检测、关卡管理、UI
├── level_transition.py    # 关卡过渡动画 - 过场特效、粒子系统
├── map_editor.py          # 地图编辑器 - 自定义地图、保存/加载
├── README.md
└── .gitignore
```

## 快速开始

```bash
# 安装依赖
pip install pygame

# 启动游戏
python main.py
```

## 操作说明

| 按键 | 功能 |
|------|------|
| WASD / 方向键 | 移动坦克 |
| 空格 | 射击 |
| P | 暂停/继续 |
| R | 重新开始（游戏结束/通关后） |
| O | 跳过关卡过渡动画 |
| ESC | 退出游戏 |

## 🗺️ 自定义地图（特色功能）

游戏内置地图编辑器，可自由设计关卡地形。

### 如何进入

在**开始界面**按 **C 键** 即可进入地图编辑器。

### 编辑操作

| 按键/操作 | 功能 |
|-----------|------|
| 1 | 放置砖墙 |
| 2 | 放置钢墙 |
| 3 | 放置水地 |
| 4 | 放置老窝 |
| 5 | 擦除/清空 |
| 6 | 放置玩家出生点 |
| 左键点击 | 放置当前选中的类型 |
| 右键点击 | 擦除该格 |
| S | 保存地图 |
| 空格/回车 | 保存并使用当前地图开始游戏 |
| ESC | 退出编辑器（返回开始界面） |

### 编辑说明

- 地图为 20×15 网格，每个格子对应一种地形
- 老窝被摧毁则游戏结束，记得用砖墙保护
- 水地坦克不可通过，但子弹可以穿过
- 钢墙需要拾取手枪道具强化子弹后才能摧毁
- 玩家出生点和老窝各只能有一个，编辑器会自动处理
- 保存的地图存储在 `custom_map.json` 文件中

## 道具系统

击杀敌人 20% 概率掉落道具，玩家经过即可拾取：

| 图标 | 道具 | 效果 |
|------|------|------|
| ❄️ 雪花 | 冰冻 | 冻结所有敌人 5 秒 |
| ❤️ +号 | 加命 | 增加一条命 |
| 💣 炸弹 | 炸弹 | 炸死屏幕上所有敌人 |
| 🔫 手枪 | 强化 | 子弹速度 2 倍，可摧毁钢墙 |

## 游戏特性

- 共 5 关，每关敌人数量递增
- 砖墙可被摧毁（3 次），钢墙需强化子弹摧毁
- 水地阻隔坦克，子弹可自由穿过
- 玩家 3 条命，被击中后短暂无敌（闪烁效果）
- 敌方 AI 会追击玩家
- 关卡过渡动画（粒子特效、星星背景、文字动画），可按 O 跳过
- 敌我子弹同线相向可抵消
- 老窝保护机制：老窝被摧毁则游戏结束

## 模块说明

- **config.py**: 集中管理所有游戏常量，便于调整游戏参数
- **sprites.py**: 所有游戏对象的类定义，每个类职责单一
- **game_manager.py**: 核心游戏逻辑，包括初始化、更新循环、碰撞处理、关卡切换、UI渲染
- **level_transition.py**: 独立的关卡过渡动画模块
- **map_editor.py**: 独立的地图编辑器模块，支持网格编辑、保存/加载 JSON
